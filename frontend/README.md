# 🎙️ Text-to-Speech Application — Frontend

A modern React + Vite frontend for a full-stack Text-to-Speech application.

## 🚀 Features

- 🔐 User Login
- 📝 User Registration
- 🎙️ Text-to-Speech generation
- 🌍 Multiple language support
- 🗣️ Voice selection
- ⚡ Speech speed control
- 📜 Speech history
- ❤️ Favorite voices
- 👤 User profile
- ⚙️ Application settings
- 🎨 Responsive and modern UI

## 🛠️ Tech Stack

- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- REST API
